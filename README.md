# PDF Tools for Windows

Небольшие программы для работы с PDF в Windows.

## Возможности

- объединение нескольких PDF и изображений в один PDF;
- естественная сортировка файлов по имени;
- разделение PDF на отдельные страницы;
- сохранение страниц в PDF или JPG;
- сборка в самостоятельные `.exe`-файлы.

## Запуск из исходников

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Объединение файлов:

```powershell
python merge_pdf.py файл1.pdf файл2.pdf изображение.jpg
```

Разделение PDF:

```powershell
python split_pdf.py документ.pdf
```

Для сохранения страниц в JPG нужен Poppler. Его можно положить в папку
`poppler\Library\bin` рядом со скриптом или добавить в `PATH`.

## Сборка для Windows

Без встроенного Poppler:

```powershell
.\build_windows.ps1
```

Со встроенным Poppler:

```powershell
.\build_windows.ps1 -PopplerPath "C:\путь\к\poppler"
```

Готовые файлы появятся в папке `dist`:

- `merge_pdf.exe`
- `split_pdf.exe`

## Добавление в меню "Отправить"

Чтобы программы появились в контекстном меню Windows:

1. Соберите `.exe`-файлы или положите готовые `merge_pdf.exe` и `split_pdf.exe`
   в удобную постоянную папку, например `C:\PDF Tools`.
2. Нажмите `Win + R`.
3. Введите:

```text
shell:sendto
```

4. В открывшейся папке создайте ярлыки на программы:

- `merge_pdf.exe` можно назвать `Объединить в PDF`;
- `split_pdf.exe` можно назвать `Разделить PDF`.

После этого можно выделить файлы, нажать правой кнопкой мыши и выбрать:

```text
Отправить -> Объединить в PDF
```

или:

```text
Отправить -> Разделить PDF
```

Для объединения можно выделить несколько PDF или изображений. Для разделения
нужно отправлять один PDF-файл.

Папки `.venv`, `build`, `dist` и временные файлы не публикуются в GitHub.
